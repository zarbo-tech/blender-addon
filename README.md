## Описание
Расширение для Blender для просмотра моделей в дополненной реальности (AR)

_В качестве платформы для хранения и визуализации 3D контента в дополненноой реальности используется [Zarbo](https://zarbo.tech/). Для использования расширения вам следует обзавестись API-Key_

## Использование
### Быстрый старт
#### Установка addon
1) В корне addon создать файл .env
2) **ZARBO_API_HOST** заполнить параметром нужным стендом
3) Переименовать папку addon в **blender-addon** 
4) Создать zip архив с папкой blender-addon (папка с проектом)
5) В **UI** блендера необходимо нажать **Правка** > **Настройки** > **Аддоны** > **Install from Disk** > и необходимо указать путь до архива с аддоном.
6) Заполнить API-Key
