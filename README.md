## Описание
Расширение для Blender для просмотра моделей в дополненной реальности (AR)

_В качестве платформы для хранения и визуализации 3D контента в дополненноой реальности используется [Zarbo](https://zarbo.tech/). Для использования расширения вам следует обзавестись API-Key_

## Использование
### Установка addon
1) Переименовать папку addon в **blender-addon**
2) Создать zip архив с папкой blender-addon (папка с проектом)
3) В **UI** блендера необходимо нажать 
   1) **Правка** > **Настройки**  
   ![img.png](image/img.png)
   2) **Аддоны** > **Install from Disk**  
   ![img.png](image/img2.png)
   3) Необходимо выбрать архив с Аддоном  
   ![img.png](image/img3.png)
   4) Необходимо ввести **API Key**, который можно получить в ЛК  
   ![img.png](image/img4.png)
